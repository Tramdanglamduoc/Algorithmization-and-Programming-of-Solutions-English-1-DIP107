# Algorithmization-and-Programming-of-Solutions-English-1-DIP107 (C language)
Course materials and solutions for DIP107 - Algorithmization and Programming of Solutions (English) at Riga Technical University. Implemented in C.

This repository contains lecture notes, practical work solutions, and practice exercises for the RTU course DIP107 — Algorithmization and Programming of Solutions (English).

Topics covered include algorithm design and flowcharts, fundamental data types, flow control, loops, arrays, and subprograms, implemented in the C programming language.

Structure:
- Lectures/ - course material and notes
- Practical Works/ - practical assignments
- Practice/ - additional exercises and self-study code
